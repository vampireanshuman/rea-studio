# Contributing to REA Studio

Thank you for considering contributing to REA Studio! Open-source community feedback, feature proposals, and pull requests help make REA Studio better for everyone.

---

## Code of Conduct

Please be respectful, collaborative, and constructive when opening issues, submitting pull requests, or participating in discussions.

---

## How Can I Contribute?

### 1. Reporting Bugs
- Check the [Issues tab](https://github.com/vampireanshuman/rea-studio/issues) first to see if your bug has already been reported.
- If not, open a new issue with a clear title and description.
- Include steps to reproduce, expected behavior, and your operating system / Node.js version.

### 2. Suggesting Enhancements
- Open a feature request issue describing the enhancement and why it would be beneficial.
- Mockups, code snippets, or architecture diagrams are highly appreciated!

### 3. Pull Requests
1. Fork the repo and create your branch from `main`.
2. Install dependencies: `npm install`.
3. If you've added new features or UI components, make sure the app launches cleanly (`npm start`).
4. Ensure your code adheres to consistent code formatting and clean commit messages.
5. Submit your pull request with a descriptive summary of your changes.

---

## Development Setup

```bash
git clone https://github.com/vampireanshuman/rea-studio.git
cd rea-studio
npm install
npm start
```
